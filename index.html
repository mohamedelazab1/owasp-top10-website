Difficulty Map

From Beginner to Expert

Each vulnerability is rated based on how easy it is to discover and exploit. Start with the green ones and work your way up.

Easy Beginner friendly — found with basic tools, often by accident.
Medium Requires understanding of HTTP, sessions, and basic scripting.
Hard Requires deep protocol knowledge, chained exploits, and creativity.
Expert Multi-step, business-logic flaws, race conditions, or novel research.

Two Sides of the Same Coin

Front-end vs. Back-end

Every vulnerability has an attack surface on the client, the server, or — most dangerously — both.

🖥️

Front-end (Client-side)

Vulnerabilities that live in the browser, DOM, JavaScript, and what the user controls.

  • XSS — Stored, Reflected, DOM-based
  • CSRF — Cross-site request forgery
  • Clickjacking — UI redress attacks
  • DOM-based issues — Insecure JS sinks & sources
  • Insecure storage — Tokens in localStorage
  • Open redirects — Trust boundary issues
⚙️

Back-end (Server-side)

Vulnerabilities that live on the server, in the database, and in the business logic.

  • SQLi — Database compromise
  • RCE — Remote code execution
  • SSRF — Internal network access
  • IDOR — Broken access control
  • Deserialization — Object injection
  • Auth bypass — Broken authentication
